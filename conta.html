Seu progresso no computador e no celular

Com a mesma conta nos dois aparelhos, você pode manter leitura, planejamento, registros de questões e revisões sincronizados. As marcações já feitas são preservadas na primeira conexão.

Sincronização ainda não ativada

O site continua salvando normalmente neste navegador. Para ativar a sincronização, é necessário conectar um projeto Supabase privado, aplicar as políticas RLS e preencher assets/sync-config.js.

Não cole senha, chave secreta ou token pessoal no GitHub. Apenas a chave pública publishable/anon pode ficar no JavaScript, depois de validar RLS.

Instruções de ativação

Entrar ou criar conta

Cadastre-se apenas no site. A senha é enviada diretamente ao Supabase por HTTPS, não ao GitHub nem ao ChatGPT. O cadastro pode exigir confirmação por e-mail.

Conta conectada

Como funciona

Na primeira conexão de cada aparelho, as subseções já marcadas como Lido são reunidas. Depois disso, marcar e desmarcar são sincronizados quando houver internet; alterações simultâneas conflitantes priorizam a alteração local mais recente detectada pelo aparelho.

O site continua funcionando sem internet. O backup JSON permanece disponível e é recomendado antes da primeira sincronização.

Uma conta é pessoal. O progresso não é publicado no repositório; o banco usa regras de acesso por usuário. A ausência de configuração Supabase significa que a sincronização está desativada.
